# Laboratory Work #4: Package Energy (Variant 5)

Пакет `energy` предназначен для расчёта объёмов потребления электроэнергии, 
вычисления базовой стоимости начислений, 
применения персональных скидок и формирования итоговых отчетов.

## 📦 Структура проекта

Проект организован в соответствии с общепринятым [Standard Go Project Layout](https://github.com/golang-standards/project-layout):

```text
.
├── cmd/
│   └── app/
│       └── main.go       # Точка входа для демонстрации работы пакета
├── pkg/
│   └── energy/
│       └── energy.go     # Основная логика пакета (Вариант 5)
├── go.mod                # Файл инициализации Go-модуля
└── README.md             # Документация проекта
```

минимальная версия go: 1.20

gofmt -w .
go run ./cmd/app/main.go
